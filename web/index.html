这个版本可以做什么

支持 OpenAI 兼容 API（Responses API）和不联网的模板模式。远程模型负责分析需求、选择参考模板、指出未实现需求和建议；Rust 负责模板布局、BOM、示意检查与保存。每个项目单独记录实际分析来源。

尚未实现的工程能力

未连接器件实时数据库、真实原理图工具、自动布线、电气仿真或生产流程。模型建议不代表功能已经实现，界面连线是模块级示意，不是管脚级网表。

本地服务没有账号或权限系统，不要开放公网。项目明文保存于本机；启用远程模型后，获授权的需求会发送至配置的 API 服务。不要输入敏感资料，API 服务商及其上游的数据政策不由本应用控制。

工作空间设置

请显式填写所用服务的 HTTPS API 地址，以 /v1 结尾。OpenAI 兼容 API 是协议标识，不代表自定义网址是 OpenAI 官方服务。

密钥仅驻留本地服务内存，重启后需重新输入；不会保存至浏览器或项目。地址不变时空密钥保留当前值，变更 API 地址必须重新输入密钥。

模型名称须与所用 API 服务的可用模型名称完全一致；保存配置不会校验模型调用权限。当前仅支持 Responses API（/v1/responses），不保证兼容仅支持 Chat Completions 的服务。

排查兼容问题时，可在网页将输出格式选为 Text JSON（text），无需设置环境变量；推理强度可选“不发送”。这些选项仅在你明确修改并保存后生效，不会自动调整。

独立于模型 API，仅向 api.mouser.com 查询。密钥不持久化，空值保存会清除密钥。库存和价格为查询时数据，不自动代表器件适用性。

仅执行明确配置的本机程序，路径不接受命令行参数。工具链只处理已生成的受约束工程，单个步骤最多运行 120 秒。
